## 1.项目概述

### 1.1项目目标

构建一个具有专业视觉效果的游戏启动器，支持：
-多游戏管理（当前2款）
-版本检查与热更新
-优雅的UI动画和过渡效果
-进程验证防破解

### 1.2技术栈

- **引擎**: Godot4.x
- **语言**: GDScript
- **UI系统**: Godot内置Control节点
- **动画**: Tween + AnimationPlayer
- **Shader**:用于背景模糊和选中效果
- **网络**: HTTPRequest

### 1.3已废弃

- ~~ECS插件~~ -本项目以UI为主，使用传统Node结构更合适

## 4.核心系统详解

### 4.1场景切换与过渡系统

**三种过渡方式：**

#### A.硬切过渡(Hard Cut)

-直接黑屏
-右下角显示"加载中..."
-加载完成后取消黑屏

- **适用**：快速切换，不需要视觉效果时

#### B.动画过渡(Animation)

-使用AnimationPlayer播放自定义动画
-可以是淡入淡出、滑动等

- **适用**：需要品牌感的场景切换

#### C. Shader模糊过渡(Advanced)

-整个画面逐渐模糊
-右下角显示"加载中..."
-模糊度从0%到100%，然后切换场景，再从100%到0%

- **适用**：主菜单内页面切换，显得高级

### 4.2全局弹窗系统

**设计原则：**
-弹窗本身无内容，只提供框架
-内容由调用方传入配置
-支持模态(不可点击背后)和非模态

**节点结构：**

```
GlobalPopup (CanvasLayer)
├── DimBackground (ColorRect -半透明黑色遮罩)
├── PopupPanel (PanelContainer)
│ ├── BackgroundBlur (TextureRect + Shader)
│ ├── MarginContainer
│ │ └── VBoxContainer
│ │ ├── TitleLabel (Label -标题)
│ │ ├── ContentContainer (MarginContainer)
│ │ │ └── [动态内容]
│ │ └── ButtonContainer (HBoxContainer)
│ │ ├── CancelButton (Button -可选)
│ │ └── ConfirmButton (Button)
│ └── CloseButton (Button -右上角X,可选)
```

**打开/关闭动画：**
-打开：从中心缩放 +淡入
-关闭：表面变模糊后消失 /或简单淡出

**输入处理：**
-使用 `_gui_input()`或 `mouse_filter`阻止事件穿透
-点击弹窗外不关闭(除非配置允许)

### 4.2.5 下载进度实现 [待规划]

> 此功能暂未纳入当前开发计划，未来可能实现。

使用 Timer 定时器轮询进度 + request_completed 信号确认完成：

```gdscript
func download_single_file(url: String, file_name: String) -> bool:
	var http_request = HTTPRequest.new()
	add_child(http_request)
	
	var timer = Timer.new()
	timer.wait_time = 0.25
	timer.autostart = true
	timer.one_shot = false
	add_child(timer)
	
	var download_complete = false
	var final_code = -1
	
	http_request.request_completed.connect(
		func(result: int, code: int, headers: PackedStringArray, body: PackedByteArray) -> void:
			final_code = code
			download_complete = true
	)
	
	var error = http_request.request(url)
	if error != OK:
		return false
	
	while not download_complete:
		var current_bytes = http_request.get_downloaded_bytes()
		var total_bytes = http_request.get_body_size()
		if total_bytes > 0:
			download_progress_changed.emit(current_bytes, total_bytes)
		await timer.timeout
	
	timer.stop()
	_remove_http_request(http_request, timer)
	return download_success
```

### 4.3上下阴影弧效果

**实现方案：**

方法A -预渲染图片(推荐)：
-提前用PS/AI画好两张PNG
-上弧：黑色渐变从上到下透明
-下弧：黑色渐变从下到上透明
-用Tween控制透明度/位置

方法B -实时绘制(Shader)：
-用Shader绘制圆形的一部分
-更灵活但性能开销稍大

**建议使用方法A**，因为：
-效果可控，设计师可以精确调整
-性能更好
-实现简单

### 4.5 Shader需求清单

| 用途     | 效果描述         | 复杂度 |
| ------ | ------------ | --- |
| 背景模糊   | 对整个背景进行高斯模糊  | 中等  |
| 弹窗背景模糊 | 对弹窗背后的内容进行模糊 | 中等  |
| 选中高亮   | 海报四周白色发光边框   | 简单  |
| 过渡模糊   | 整个画面逐渐模糊     | 简单  |

### 4.6进程验证系统

**双向验证机制：**

1. **启动器 →游戏**：
   -启动器在指定目录生成 `.etn_launcher_pid`文件
   -内容：启动器进程PID
   -游戏启动时读取此文件验证启动器存在

2. **游戏 →启动器**：
   -游戏启动后在同目录生成 `.game_pid`文件
   -内容：游戏进程PID
   -启动器检测到文件后确认游戏已启动

**启动器端逻辑：**

```gdscript
#启动游戏前
func launch_game():
 #1.写入启动器PID
 var pid_file = game_dir.path_join(".etn_launcher_pid")
 FileAccess.open(pid_file, FileAccess.WRITE).store_string(str(OS.get_process_id()))

 #2.启动游戏进程
 OS.create_process(game_exe_path, [])

 #3.等待游戏PID文件出现
 await wait_for_game_pid()

 #4.更新UI状态为"运行中"
 update_card_state(CardState.RUNNING)
```

```glsl
shader_type canvas_item;

uniform float blur_amount : hint_range(0.0,5.0) =2.0;

void fragment() {

 COLOR = color;
}
```

**步骤2.2:选中高亮Shader**

```glsl
// highlight_border.gdshader
shader_type canvas_item;

uniform float border_width : hint_range(0.0,0.1) =0.02;
uniform vec4 border_color : source_color = vec4(1.0,1.0,1.0,1.0);
uniform float glow_intensity : hint_range(0.0,2.0) =1.0;

void fragment() {
 vec2 uv = UV;
 vec4 tex_color = texture(TEXTURE, uv);

 //计算到边缘的距离
 float dist_to_edge = min(min(uv.x,1.0 - uv.x), min(uv.y,1.0 - uv.y));

 //如果在边框范围内
 if (dist_to_edge < border_width) {
 float alpha = (1.0 - dist_to_edge / border_width) * glow_intensity;
 tex_color = mix(tex_color, border_color, alpha);
 }

 COLOR = tex_color;
}
```

###6.2页面切换实现

```gdscript
#主菜单页面切换
extends Control

@onready var page_container = $PageContainer
@onready var page_indicator = $PageIndicator

var current_page =1 #默认第2页(索引1)
var total_pages =3
var is_switching = false

func _input(event):
 if event is InputEventMouseButton and event.pressed:
 if event.button_index == MOUSE_BUTTON_WHEEL_UP:
 switch_page(-1)
 elif event.button_index == MOUSE_BUTTON_WHEEL_DOWN:
 switch_page(1)

func switch_page(direction: int):
 if is_switching:
 return

 var target_page = clamp(current_page + direction,0, total_pages -1)
 if target_page == current_page:
 return

 is_switching = true

 #使用Shader模糊过渡
 await SceneManager.transition_with_blur()

 #切换页面
 current_page = target_page
 update_page_display()

 is_switching = false

func update_page_display():
 #移动page_container
 var target_x = -current_page * get_viewport().size.x
 var tween = create_tween()
 tween.tween_property(page_container, "position:x", target_x,0.3)

 #更新指示器
 page_indicator.set_active_page(current_page)
```

##8.重要设计决策记录

本节记录开发过程中的关键决策和约定，确保后续开发一致性。

###8.1技术约束与约定

#### TSCN文件保护原则
**决策**:绝不修改用户现有的 `.tscn`场景文件
**原因**:曾出现文件损坏无法恢复的严重后果
**执行**:所有新功能通过新建脚本和组件实现，不触碰已有场景

####资源加载方式
**决策**:统一使用 `load()`而非 `preload()`
**原因**:支持后续补丁更新机制，避免预加载造成干扰
**例外**:Shader等极小资源可使用 preload（不影响热更新）

#### CanvasLayer层级管理
**决策**:使用 CanvasLayer节点替代 Z-Index管理UI层级
**层级规划**:
```
Layer0:背景、游戏世界内容
Layer1:普通UI界面
Layer2: HUD抬头显示
Layer3:弹窗背景遮罩（压暗效果）
Layer4:弹窗内容
Layer5:加载界面、Toast提示（最上层）
```
**使用方法**:
1.在编辑器中添加 CanvasLayer节点作为父节点
2.在 Inspector中设置 Layer属性（0-128）
3.将同层级的UI节点放入该 CanvasLayer下

###8.2视觉实现方案

####选中高亮边框
**决策**:使用预渲染的 Texture+Tween动画，不使用 Shader
**实现**:
1.绘制白色发光边框PNG（中间透明，四周发光）
2.放在海报上方作为 overlay层
3.默认隐藏，鼠标悬停时用 Tween控制透明度0→1
4.支持打断动画（鼠标快速进出时动画平滑过渡）

####阴影弧效果
**决策**:同样使用预渲染图片+Tween
**触发逻辑**:
-鼠标进入卡面区域→阴影弧渐显（Tween从0%到100%透明度）
-鼠标离开卡面区域→阴影弧渐隐（Tween从当前值到0%）
-反复进出会打断当前动画，产生自然的过渡效果

####模糊效果使用范围
**决策**:仅保留 `transition_blur.gdshader`
**用途**:
-主菜单背景模糊（显示游戏海报的模糊版本）
-弹窗背景的毛玻璃效果
-场景切换时的全屏模糊过渡（通过调整可见度实现）
**废弃**:白色发光边框 Shader（改用Texture实现）

## 9.全局弹窗系统详细设计（Glass Popup System）

### 9.1架构概述

基于液态玻璃效果的全局弹窗系统，支持动态按钮生成、元数据回调、Shader动画效果。

**核心组件（位于 `component/GlassComponent/`）：**
- `PopupManager`（单例）：统一入口，管理弹窗生命周期
- `GlobalPopup`（脚本 + 场景）：实际弹窗UI，动态构建内容
- `GlassButton`：玻璃效果按钮组件
- `GlassPanel`：玻璃面板（可选使用）

### 9.2文件结构

```
component/GlassComponent/
├── global_popup.gd      # 弹窗逻辑脚本
├── global_popup.tscn    # 弹窗场景
├── glass_button.gd      # 按钮组件脚本
├── glass_panel.gd       # 面板组件脚本（可选）
├── medium_popup.tscn    # 中等尺寸弹窗场景
└── large_popup.tscn     # 大尺寸弹窗场景
```

### 9.3节点层级结构

```
CanvasLayer (Layer =4)
└── GlobalPopup (脚本挂载点)
 ├── DimBackground (ColorRect -半透明黑色遮罩,可选)
 └── GlassPanel (ColorRect + liquid_glass_ui shader)
  └── MarginContainer
   └── VBoxContainer
    ├── TitleLabel (Label)
    ├── ContentContainer (MarginContainer)
    │ └── [ContentLabel/RichTextLabel]
    ├── Spacer (Control, size_flags_vertical =3)
    └── ButtonContainer (HBoxContainer, alignment = CENTER, separation = 16)
```

### 9.4配置格式规范

### 9.5按钮类型详解

**三种按钮类型：**

| 类型 | 用途 | 颜色特征 |
|------|------|----------|
| primary | 主要操作（确定、执行） | 蓝色系 |
| secondary | 次要操作（取消、返回） | 灰色系 |
| third | 第三选项（不确定、稍后） | 绿色系 |

**按钮排序规则：**
- 自动按 primary → secondary → third 排序（从左到右）
- 即使配置顺序不同，显示时也会自动重排

**按钮尺寸：**
- 默认：140 x 48 (medium), 180 x 56 (large)
- 可通过 `min_width` / `min_height` 自定义

### 9.7回调机制设计

**解耦原则：**
- 弹窗本身不处理业务逻辑，只负责UI展示
- 按钮通过 metadata 标识，而非直接绑定功能
- 所有按钮点击都通过 `popup_button_pressed` 信号转发

**使用示例：**
```gdscript
#调用方代码
func _on_delete_clicked():
 PopupManager.show_popup({
  "title": "确认删除",
  "content": "确定要删除这个存档吗？",
  "buttons": [
   {"text": "取消", "type": "secondary", "metadata": "cancel"},
   {"text": "删除", "type": "primary", "metadata": "delete"}
  ]
 })
 PopupManager.popup_button_pressed.connect(_handle_popup_response)

func _handle_popup_response(metadata: String):
 match metadata:
  "delete":
   _perform_delete()
  "cancel":
   pass #什么都不做
 PopupManager.popup_button_pressed.disconnect(_handle_popup_response)
```

### 9.8动画效果规范

**打开动画：**
- scale: 0.8 → 1.0 (0.3s, TRANS_BACK, EASE_OUT)
- modulate.a: 0 → 1 (0.25s)
- 同时触发

**关闭动画（标准）：**
- modulate.a: 1 → 0 (0.15s)
- 完成后 queue_free()

**关闭动画（带Shader模糊）：**
- blur_amount: 0 → 2.0 (0.15s) - Shader参数
- modulate.a: 1 → 0 (0.15s) -淡出
- 需要 ColorRect 覆盖整个面板，应用 transition_blur shader

### 9.9按钮布局规则

**布局特性：**
- 居中对齐（ALIGNMENT_CENTER）
- 按钮间距：16px
- 自动排序：primary → secondary → third

**1个按钮：**
```
HBoxContainer (alignment = CENTER)
└── Primary Button
```

**2个按钮：**
```
HBoxContainer (alignment = CENTER, separation = 16)
├── Primary Button (左)
└── Secondary Button (右)
```

**3个按钮：**
```
HBoxContainer (alignment = CENTER, separation = 16)
├── Primary Button   (左)
├── Secondary Button (中)
└── Third Button     (右)
```
